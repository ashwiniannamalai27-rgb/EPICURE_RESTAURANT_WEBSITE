SYSTEM ARCHITECTURE

A Modern Vanilla & Bootstrap Architecture

The ÉPICURE platform is engineered using modern standards-based front-end development practices. Without heavy external frameworks, it achieves ultra-fast load times, responsive fluid layouts across all viewport sizes, and seamless state management for fine-dining interactive modules like real-time menu filtering, sommelier pairings, and multi-course menu construction.

FOUNDATION

Core Technology Stack

HTML Semantic

Structured with W3C-compliant semantic tags (<header>, <main>, <article>, <aside>) and accessible data-* attributes for seamless script querying.

CSS & Keyframes

Custom design token system with CSS custom properties, responsive flex/grid modules, and GPU-accelerated keyframe animations for diagonal metallic sheens and soft glowing states.

Bootstrap 5.3.3

Modern mobile-first grid, responsive navigation collapses, dismissible Toasts, centered dynamic Modals, and the Offcanvas drawer for the tasting menu summary.

ES6+ JavaScript

Decoupled event-driven UI logic, dynamic currency regex formatting, multi-criteria filtering pipelines, synchronized state management, and URL parameter encoders.

COMPONENT INVENTORY

Technical Deep Dive by Category

A detailed breakdown of all HTML elements, CSS specifications, Bootstrap APIs, and JavaScript functions utilized across the project.

Clean HTML document structures optimized for screen readers and high search engine discoverability.
  • <header>, <nav>, <main>, <footer>, <aside> — Semantic structural landmarks.
  • <article class="menu-card"> — Self-contained dish cards containing accessible attributes.
  • data-category, data-diet, data-name — Data attributes used by JavaScript query engines.
  • data-pair-drink, data-pair-why, data-pair-side — Rich metadata for pairing lookups.
  • aria-label, role="button", tabindex="0" — WAI-ARIA standards for keyboard navigation and screen-reader accessibility.

Utilizing the responsive modularity of Bootstrap 5.3 without relying on jQuery:
  • Offcanvas (#tastingOffcanvas): Sliding side drawer rendering the multi-course progression and checkout link.
  • Modal Dialog (#dishModal): Centered modal inspecting dish ingredients, ratings, prices, and pairing notes.
  • Grid System: .container, .row, .col-md-6, .col-lg-4 with responsive gutter utilities (g-4).
  • Toast (#siteToast): Fixed-position notifications for user confirmations.
  • Responsive Navbar: Collapsing mobile menu with burger toggle and gold CTA reservation link.

Advanced CSS crafting the signature dark luxury atmosphere:
  • @keyframes goldSheen — Diagonal metallic shimmer sweeping across menu cards on hover.
  • @keyframes menuFadeIn — Smooth scale and translation entrance for cards matching active filters.
  • @keyframes slideUpTasting — Smooth slide-in animation for the floating tasting menu bar.
  • Dietary Indicators: Indian standard green circle (Veg) and red triangle (Non-Veg) badge styling.
  • Gold Theme Tokens: Consistent branding palette using #c5a059 and #e6ca85 accents against deep charcoal backgrounds.

Clean, performant client-side scripts written in modern vanilla JavaScript:
  • Compound Filter Pipeline: Evaluates active category, active dietary restriction, and search keyword in a single linear pass (O(N)).
  • Tasting Menu State Machine: Maintains an internal state object tracking courses, computing totals, and updating UI slots dynamically.
  • Currency Parser & Formatter: Converts INR strings into integers, accumulating bill totals and rendering formatted strings with Indian number formatting (toLocaleString('en-IN')).
  • Deep Link Generator: Encodes user-selected menu items into clean URL search parameters (encodeURIComponent) passed directly to reservation.html.
